# Lumen 7 · © Gaerisson

Vibecodé avec OpenAI Codex.

Lance Lumen.exe. Ctrl+Alt+L ouvre les réglages ; Ctrl+Alt+Espace libère les écrans. Les fenêtres sont réductibles et leurs positions sont mémorisées.

Modules & PC distants permet de choisir les connecteurs, le mode économe, les thèmes automatiques et le partage du quota/CPU/RAM. Le serveur est désactivé par défaut, avec une clé de jumelage locale chiffrée.

Pour un autre PC, extrais une archive propre. Ne transfère pas data/ : les clés sont liées au profil Windows. Connecte Home Assistant ou jumelle le PC Codex dans les options.

La musique utilise un lecteur Home Assistant, y compris Spotify si cette intégration y est configurée. La reprise Codex est facultative : elle exige une erreur explicite de quota, un quota disponible et respecte les instructions des projets. Les brouillons Codex non envoyés ne sont pas lus.

README.md détaille les modules, les limites, l’installation et le développement. SECURITY.md explique le partage distant. Les marques des connecteurs appartiennent à leurs détenteurs, sans affiliation officielle.
