# Lumen 7.1 · © Gaerisson

Vibecodé avec OpenAI Codex.

Lance Lumen.exe. Ctrl+Alt+L ouvre les réglages ; Ctrl+Alt+Espace libère les écrans. Les fenêtres sont réductibles et leurs positions sont mémorisées.

Modules & PC distants permet de choisir les connecteurs, le mode économe, les thèmes automatiques et le partage du quota/CPU/RAM. Le serveur est désactivé par défaut, avec une clé de jumelage locale chiffrée.

Pour un autre PC, extrais une archive propre. Ne transfère pas data/ : les clés sont liées au profil Windows. Connecte Home Assistant ou jumelle le PC Codex dans les options.

Spotify se connecte directement avec un assistant dans Modules & PC distants. Il faut créer une application Spotify et renseigner son Client ID public, jamais de Client Secret. Les jetons sont chiffrés localement. La reprise automatique Codex est retirée.

Audio & réveil propose NRJ, RFI, franceinfo, un podcast personnel ou un flash lu localement, avec préécoute des flux et de la voix. La veille utilise les fenêtres existantes pour éviter les doublons dans la barre des tâches.

[README.md](../README.md) détaille les modules, les limites, l’installation et le développement. [SECURITY.md](../SECURITY.md) explique le partage distant. Les marques des connecteurs appartiennent à leurs détenteurs, sans affiliation officielle.
